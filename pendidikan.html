Karhutla, singkatan dari kebakaran hutan dan lahan, hampir selalu bermula dari hal yang bisa dicegah. Memahami dari mana api bermula membuat kita tahu di mana harus bertindak lebih dulu: di ladang, di lahan gambut, di rumah, dan di sekolah.

Dari mana api bermula

Pembukaan lahan dengan membakar

Membakar sisa tebasan dianggap cepat dan murah. Saat angin kencang dan tanah kering, api mudah lepas dari petak yang dibuka dan menjalar ke hutan di sekitarnya.

Musim kemarau panjang

Kemarau, apalagi saat El Niño, mengeringkan semak, serasah, dan tanah. Cuaca kering membuat percikan kecil mudah menjadi kebakaran besar.

Lahan gambut yang kering

Gambut yang dikeringkan lewat kanal mudah terbakar. Apinya bisa membara di bawah tanah, sehingga sulit terlihat dan sulit dipadamkan.

Kelalaian sehari-hari

Puntung rokok, api unggun yang tidak dipadamkan, atau sampah yang dibakar di dekat semak kering bisa menjadi pemicu.

Cara mencegahnya

Pencegahan bekerja paling baik jika dilakukan di tiga tingkat sekaligus.

  • Di lahan: bersihkan lahan tanpa membakar, jaga gambut tetap basah dengan sekat kanal, dan buat sekat bakar di tepi kebun.
  • Di desa: bentuk dan latih regu pemadam desa seperti Masyarakat Peduli Api, lakukan patroli saat musim kemarau, dan sepakati aturan larangan membakar.
  • Di rumah dan sekolah: jangan membuang puntung rokok sembarangan, padamkan api unggun sampai dingin, dan ajak teman serta keluarga ikut berbagi informasi.
  • Dengan informasi: pantau titik panas dan peringatan cuaca dari BMKG dan KLHK sebelum membuka lahan atau berkemah.

Belajar dari kearifan lokal

Banyak komunitas punya aturan sendiri untuk menjaga api tetap terkendali. Masyarakat Dayak, misalnya, mengenal pola berladang yang mengatur kapan dan di mana lahan dibuka. Pengetahuan seperti ini layak masuk ke pelajaran muatan lokal, diceritakan langsung oleh para tetua dan petani setempat.

Jika melihat api

Jika api masih kecil dan aman dijangkau, padamkan dengan air atau tanah.

Jika api membesar, menjauh dan jangan mencoba memadamkannya sendirian.

Segera hubungi perangkat desa, BPBD setempat, atau nomor darurat 112, dan sebutkan lokasi sejelas mungkin.
